run/attempt/compiler context. Its narrow checkout-diff allowlist refuses compiler,
adapter, actual native fixtures, configuration, runtime lockfiles, admission/build

preventing source-tree fallback. Every package loads; API packages execute

without retry/logging. Synthetic inspector/observer modules are never output or
