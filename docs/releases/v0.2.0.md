# amail v0.2.0

Community subscriptions and explicit human-authorized resource budgets, with
fixed USD pricing and matching agent-first recovery commands.

| Plan | USD/month | Monthly outbound recipients | Storage | Included addresses |
| --- | ---: | ---: | ---: | ---: |
| Free | 0 | 100 | 200 MB | 1 |
| Lite | 1.50 | 1,000 | 2 GB | 3 |
| Plus | 4.50 | 5,000 | 10 GB | 5 |

Shared overage is USD0.001 per accepted distinct envelope recipient,
USD0.15/decimal GB-month and USD0.50/address-month. Stock usage is prorated by
actual byte/address time. Inbound has no per-message charge; retained-message
count and semantic search have no commercial quota. Sending policy and technical
abuse protections remain independent. The default overage budget is zero.

## Authorization and compatibility

- `amail billing status`, `subscribe`, `manage` and `session` expose authoritative
  resources and recoverable human authorization. Only the human browser can
  approve paid access and spending; an agent cannot raise the cap.
- Existing addresses and mailbox content survive migration. Existing accounts
  become Free, with existing registered addresses grandfathered intact.
- New API protocol requires v0.2.0 clients; old clients receive typed HTTP426
  upgrade guidance. Upgrade the CLI and matching Skill together. Local production
  defaults and encrypted credentials do not need reinitialization.
- One USD is 1,000,000 integer micros. Historical CNY receipts/liabilities retain
  CNY, never become USD consent, and never mix with USD totals.
- Billing still uses one-use activation grants and `pending_settlement` usage.
  Authorization, a return-page visit and ledger acceptance are not proof of a
  monetary payment. No payment processor or automatic recurring debit is added.

## Privacy and recovery

Closed typed tracing connects CLI, Mail, Subscribe, Billing and asynchronous
scheduled usage delivery without retaining mail content or credentials in public
HTTP logs. Preserve the original send/authorization idempotency key after an
unknown result; query that intent rather than blindly creating another action.

Automatic indexing still sends the first 12,000 UTF-8 bytes of eligible mail's
subject/body to OpenRouter and upstream providers, even without semantic search.
Raw ZIPs and attachments are not indexing inputs. Semantic queries are also sent;
query/vector state can remain for up to 24 hours. There is no account opt-out;
diagnostic telemetry settings do not disable indexing.

## Downloads

Five native platform archives, the matching USD agent Skill ZIP and `SHA256SUMS`
are attached. Verify checksums and artifact attestations before installing.
CLI publication alone is not evidence that a remote environment has upgraded;
check authoritative service/plan status after connecting to the intended realm.
