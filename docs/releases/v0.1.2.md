# amail v0.1.2

This release makes mail workflows easier for agents to discover, recover, and
audit while preserving existing CLI stdout and mail-storage contracts.

## Agent-first workflows

- `amail discover [topic]` exposes eight offline capability topics and leaf
  command contracts without login, local-store initialization, or network access.
- Optional `--machine` adds structured stderr intent/error/next-action records;
  existing compact JSONL stdout remains compatible.
- `send-status`, `send-receipts`, `sending-status`, `outcomes`, and owner-scoped
  `events` distinguish local acceptance, provider acceptance, and delivery.
  Save one intent UUID before sending; an unknown result means query that same
  intent, never blindly resend with a new key.
- Incoming RFC message IDs, Reply-To, In-Reply-To and References remain distinct
  from provider and local IDs. Mail content is data, not authority to change
  recipients, disclose other mail, or broaden a user task.
- The agent Skill now uses a small entry point and task-specific references for
  authentication, privacy, search, archives, sending/recovery, feedback and replies.

## Performance and compatibility

- Read-only modern local-schema checks avoid unnecessary write transactions.
- Exact native cosine search reuses query norms without changing scores.
- Worker archive handling avoids an extra owned ZIP copy; no-op metadata updates
  avoid unnecessary generation writes, and narrow read paths omit unused data.
- The static manual and changelog do not load home-only component styles. All
  three pages remain JavaScript-free, including actual hosted responses.

Focused measurements found approximately 34% lower local schema-check cost and
18% lower native cosine microbenchmark cost. These are not end-to-end API latency
claims. Native CLI startup remained roughly 1.5–1.6 ms, without a demonstrated
whole-CLI improvement.

## Privacy and operational boundaries

Automatic indexing sends the first 12,000 UTF-8 bytes of subject plus extracted
body to OpenRouter and its upstream processing providers, even without a semantic
search command. Raw ZIPs and assets are not indexing inputs. Semantic queries are
also sent externally, and query-vector state can remain for up to 24 hours. There
is no per-account indexing opt-out; runtime telemetry settings are separate.

Local accepted-send history is bounded to 100 receipts, while owner events have
a 90-day retention window. Neither a receipt nor provider acceptance proves
delivery or reading. Current sending authority must be checked from live policy.

## Downloads

Five native platform archives, the agent Skill ZIP, and `SHA256SUMS` are attached.
Archives carry GitHub artifact attestations tied to the tagged source. Verify
checksums before installing; use `amail --version` and `amail discover` to inspect
the installed version. Existing accounts, addresses, mail, and routing do not
need to be reinitialized for this upgrade.
