- **远程终端登录。** 使用 `amail login --device-code --no-browser`，在自己的手机或电脑核对应用名称与验证码后批准。不需要终端所在设备接收回环回调；默认浏览器 PKCE 登录继续保留。
- **订阅短码交接。** `billing subscribe` 和 `billing manage` 可加 `--device-code`，用短码进入原有 Subscribe 确认页。输入短码或打开链接不会授权套餐、付费或预算；只有人类明确批准后的可信回执才改变权益。
- **完整会话生命周期。** 登录遵守轮询间隔及 `slow_down`，拒绝、过期和终端取消会结束本次尝试；令牌校验、受保护存储、旋转刷新与退出复用现有机制。订阅保留原创建键和会话续查，不因超时创建另一笔操作。
- **兼容既有客户端。** 原有 PKCE、订阅直达链接及已保存的账户和 Profile 保持可用；本版本不会启用 YOLO，也不会替用户授权语义处理或开支。

升级前停止旧 CLI 和 daemon，校验同一 Release 的安装包与 Agent Skill。保留凭据、配置、邮件及未决发送日志。后台需先启用 Identity 客户端设备授权，并应用增量迁移 0020；正式发布流程在完成配对部署与新构建二进制的真实登录验收后才开放下载。
