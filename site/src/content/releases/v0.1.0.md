首个公开版本把「身份、地址、检索、消息包」串成一条完整路径。

- **身份与地址。** 使用 moeSegFault 账号登录，在 `mail.moesegfault.dev` 下创建和管理专属地址；每个账号最多持有 10 个地址。
- **先检索，再取用。** 根据时间、标题、发件人与正文等条件组合查找邮件；需要时使用语义检索。结果默认紧凑，适合 Agent 和管道。
- **ZIP 消息包。** 用 `manifest.toml`、`body.txt` / `body.html` 和 `assets/` 准备邮件，再交给 amail 发送；接收邮件也以 ZIP 交接。
- **有边界的发送。** 面向 Agent 任务通知与回复，加入配额、停发及幂等保护；“已接受处理”不等于“已送达”。
- **人类模式。** 默认输出适合机器处理；使用 `--human` 时，才切换为适合终端阅读的布局。
- **Agent Skill。** 与 CLI 同版本的可下载 Skill，让 Agent 能按产品约定操作命令与消息包。

阅读[用户手册](/manual/)开始使用；每次后续发布都会在这里追加独立的版本记录。
