本版本记录永久邮箱租约的客户端修正；实际发布、定点验收和安装状态以 GitHub Release 与验收记录为准。

- **永久邮箱可正常取得占用。** 修复 `amail mailbox acquire <已拥有的永久邮箱> --mode read|write` 在服务端已经成功取得租约后，仍被 CLI 报为 `invalid mailbox lease` 的问题。永久地址合法的空代际标记（generation）现在会按原值保存在本机。
- **不放宽锁或令牌校验。** 仍由服务端执行不可抢占的多读／单写规则；Profile、会话与账号隔离、临时地址的独立存续代际、租约释放以及 JSONL 输出约定均保持不变。空能力令牌和无效模式仍被拒绝，正常输出不包含租约能力令牌。
- **只修客户端。** 不需要重新部署后端、迁移数据库或重新授权语义处理。验证聚焦租约保存、真实 acquire／release 旅程及原生发布产物检查，不重复整套已通过的功能回归。

升级前停止旧 CLI 进程与 daemon，核对同一 Release 的校验清单，并使用配套 Agent Skill。保留凭据、配置、邮件、原始发信 ZIP、幂等键和未决日志，不要为了升级重新注册地址或重发未决操作。
