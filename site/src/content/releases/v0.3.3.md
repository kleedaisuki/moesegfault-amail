本版本记录本机操作授权页的客户端修正；实际发布、定点验收和安装状态以 GitHub Release 与验收记录为准。

- **正常点击可以完成授权决定。** 修复 `user` Profile 操作授权页在点击 Approve 或 Deny 时仍返回 `Invalid authorization request.` 的问题。原来的 `Referrer-Policy: no-referrer` 会令浏览器表单提交携带 `Origin: null`，与本机来源校验冲突；现改为 `same-origin`，保留正常同源表单的来源，并继续阻止跨源来源信息泄露。
- **不放宽安全边界。** 保留精确 Host、路径、来源与一次性操作校验，仍拒绝 `null` 来源及跨源请求；不会开启 YOLO、批准未来操作或改变 Identity 登录、费用和语义处理授权。
- **只修客户端。** 不需要后端部署或数据库迁移。验收聚焦授权契约与真实浏览器原生表单的 Approve／Deny 旅程，不重复邮件全套回归。

升级前停止旧 CLI 进程与 daemon，核对同一 Release 的校验清单，并使用配套 Agent Skill。保留凭据、配置、Profile、邮件和未决发信日志，不要为了升级重新登录、注册地址或重发未决操作。
