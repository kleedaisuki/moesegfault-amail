版本记录日期不是实际发布日期；发布状态以页面说明与 GitHub Release 为准，本文不代表生产服务升级。

- **Free / Lite / Plus。** 按账户共享发信、存储与地址额度；收信不按封计费，不按留存邮件数收费，语义搜索不设套餐次数额度。超额按量结算，并受用户授权预算约束。
- **人类授权付费。** Agent 发起订阅授权，用户在 Billing 网页确认；返回页面不是付款证明，CLI 重新查询权威状态。
- **保留已有地址。** 升级前所有注册地址保留，已有账户统一归入 Free；超出包含地址数量不导致旧地址被删除。
- **明确的不兼容升级。** v0.2.0 CLI 使用新版 API 协议；旧版客户端不再支持新版服务，请同步升级，不要盲目重试失败的发送。
- **脱敏端到端遥测。** 操作关联覆盖 CLI、Mail 与 Billing；邮件、凭据和支付信息不得进入公开日志。

实际命令、授权与用量以当前客户端及服务端状态为准。此记录不替代托管端到端验收。
