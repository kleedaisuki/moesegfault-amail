这是 v0.3.0 的版本设计记录，不表示 GitHub Release 已发布或生产环境已升级。当前候选的实际验收状态以页面说明和部署记录为准；v0.2.0 的已发布资源不会被本记录替代。

- **薄客户端与守护进程。** CLI 自动连接或启动本机 daemon；配置、数据库与安装目录统一放在 `~/.amail`，Windows 对应 `%USERPROFILE%\.amail`。`config.toml` 仅覆盖需要改变的默认值。
- **按终端隔离 Profile。** 同一终端的多个 CLI 进程共享当前 Profile；一个 Profile 同时只能由一个终端激活。停用与释放不同：停用保留占用，连续 30 分钟未使用才自动释放；只有由 `user` 创建的 Profile 会保留名称。
- **人类逐次授权。** `user` 默认每次操作都需要在浏览器确认；配置中的 YOLO 是显式关闭此保护，不是 Agent 可以自行开启的权限。订阅和预算仍须单独由人类授权。
- **不可抢占的读写占用。** 同一邮箱允许多个 Profile 同时读，或一个 Profile 独占写。云端验证会话与占用，不因本机重启或另开 CLI 绕过冲突。
- **临时测试邮箱。** `tmpaddr.moesegfault.dev` 地址最长可用六小时，释放不通知、不可恢复。旧数据不可由后来复用同名地址的人取得；清理、路由退役和冷却完成后才能重新分配。需要保留的历史必须在释放前下载。
- **同一账户共享资源。** 临时地址有高于普通地址的套餐数量，但不会乘出新的发信或储存额度。普通 `mail.moesegfault.dev` 地址只允许 `user` 注册。

原有 JSONL 输出、ZIP 消息包、显式已读更新和发送意图恢复继续适用。自动第三方语义索引的隐私边界没有改变。
