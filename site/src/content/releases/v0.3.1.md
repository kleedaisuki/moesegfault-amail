本版本改变语义检索的授权边界。此处为版本记录，实际发布与远端部署以 GitHub Release 和验收记录为准。

- **默认关闭。** 新账号及升级后的账号都不再默认把邮件发送给嵌入模型；普通条件检索仍可使用。
- **user 控制开关。** `amail semantic status` 查看账户状态，`amail semantic enable` / `disable` 仅由活动的 `user` Profile 操作。默认开启网页确认，沿用人类已显式配置的 YOLO；其他 Profile 不能修改账户开关。开关影响全部 Profile。
- **Voyage 4，经 OpenRouter。** 启用后，后台为全部符合条件的保留邮件及后续新邮件建立索引。输入仍为邮件主题、正文提取文本的前最多 12,000 个 UTF-8 字节，不含原始 ZIP 和附件。语义查询也会发送给该服务。
- **关闭不清空旧向量。** 关闭后不接纳新的模型处理请求，但保留已有邮件嵌入向量（embeddings）。已经发送的请求无法撤回，过期结果不能写入新代际。
- **重新启用完整重建。** 再次启用会重新索引全部符合条件的保留邮件，包括已有旧向量的邮件；重新发送的是邮件文本，不是用旧向量转换模型。重复启用已启用状态不会再次启动全量重建。
- **独立迁移既有 embeddings。** 迁移保留旧数据并默认禁用处理，隔离旧 Qwen 与新 Voyage 向量空间，不在升级时自动把历史邮件重发给远端。尚未完成的索引不会伪装成完整结果。

诊断遥测与语义授权相互独立。升级时先停止旧 CLI 与 daemon，使用同一 Release 的二进制与 Agent Skill 并核对校验和；原始发信 ZIP、幂等键和未决日志继续保留，不因升级换键重发。
